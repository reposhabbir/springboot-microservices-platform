## Kubernetes (Deployment Layer)

This folder contains starter manifests you can expand into a full Helm/Kustomize deployment.

### Suggested next steps

- Create a `Namespace`
- Deploy Eureka + Config + Gateway
- Deploy Kafka (or use a managed Kafka)
- Add `ConfigMap`/`Secret` for service configuration
- Add `Deployment` + `Service` per microservice
- Add `Ingress` to expose the API Gateway
